Published by Heber Garza. Browsebook is available through Google Play internal testing.

Report a problem

Include your app version, Android version and a short description of what happened. Share a public example page when possible. Remove passwords, API keys and private page content from screenshots or logs.

Using your own AI provider

Browsebook AI is optional. Configure the endpoint, model and API key supplied by your provider. Provider charges are separate from Browsebook. A ChatGPT subscription does not include API usage.

Notes and snapshots

Annotations are associated with a page URL. Live snapshots reopen the current website; image snapshots preserve the captured image for offline viewing. A changed website layout can affect annotation placement.
